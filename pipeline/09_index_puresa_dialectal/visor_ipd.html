Visor de resultats de l'IPD

Carrega un fitxer JSON generat amb python ipd.py --corpus ... --sortida resultat.json per a explorar-lo frase a frase, amb les paraules ressaltades.

Arrossega ací el fitxer .json o fes clic per a seleccionar-lo
Pots carregar-ne diversos alhora per a comparar-los en pestanyes
Encara no s'ha carregat cap fitxer.
Tot el processament passa localment al navegador; els fitxers no s'envien enlloc. Ressaltat aproximat (coincidència de paraula, en minúscules) -- per a la classificació exacta, vore la columna de marcadors de cada document.
