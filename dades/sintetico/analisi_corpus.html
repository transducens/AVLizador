Corpus sintètic · comparativa de models

Qwen vs. Gemma3 vs. Salamandra — mateixa mostra, costat a costat

Carrega els fitxers corpus_qwen.jsonl, corpus_gemma.jsonl i corpus_salamandra.jsonl generats amb generar_muestra_comparativa.sh (mateix --seed, mateixes frases als 3) per a veure l'original i les traduccions de cada model juntes, amb les diferències respecte a l'original ressaltades.

01 · Carregar fitxers

Arrossega els .jsonl ací

Detecta el model automàticament (camp model de cada línia) — no cal que coincidisquen amb els noms dels fitxers. Pots carregar-ne 2, 3 o més; tots els que comparteixen el mateix id es mostraran junts.

Arrossega ací els .jsonl, o fes clic per a triar-los corpus_qwen.jsonl · corpus_gemma.jsonl · corpus_salamandra.jsonl (o els que tingues)

02 · Comparativa frase a frase

Original i traduccions de cada model

El ressaltat marca les paraules de cada traducció que no apareixen (en eixa forma) a la frase original — així es veu d'un colp d'ull què ha canviat cada model, sense haver de llegir paraula per paraula.

Tot el processament passa al navegador — els fitxers no s'envien enlloc.
